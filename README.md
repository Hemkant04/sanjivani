# Sanjivani

Sanjivani is a Nepal-based healthcare startup concept focused on nurse-led home health visits for families in Kathmandu Valley.

The idea behind Sanjivani is simple: many children live away from home, often abroad, and carry constant worry about the health and well-being of their parents. Sanjivani is designed to reduce that distance through professional home visits, clear family updates, and care that feels respectful, warm, and trustworthy.

This project is a front-end prototype built to present the startup clearly to potential clients, partners, and investors.

## Startup Vision

Sanjivani aims to create a more human and dependable model of home healthcare in Nepal.

The brand is built around:

- nurse-led home care
- dignified and compassionate elder support
- instant updates for children and caregivers
- culturally rooted service with a premium experience
- a bootstrapped, trust-first approach to growth

## What Sanjivani Offers

The current prototype presents these core service areas:

- Healthcare and routine nurse checkups
- Medication management
- Tele communication support as an upcoming service
- Wound caring and dressing
- Post surgery care

## Product Experience

The website includes:

- a premium landing page for the brand
- a dedicated services page
- an about page that explains the story and mission
- a booking/contact modal for demo purposes
- WhatsApp-based contact flow

## Tech Stack

This prototype is built with:

- Next.js
- Tailwind CSS
- Framer Motion

## Routes

- `/` - Landing page
- `/services` - Services page
- `/about` - About Us page

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev -- --hostname 127.0.0.1 --port 8000
```

Open:

```text
http://127.0.0.1:8000
```

## Build

To create a production build:

```bash
npm run build
```
